Teóricas:
1) scope -> alcance
hoisting -> elevación, por ejemplo las funciones se elevan completamente, las puedo usar antes de escribirlas
mutablidad -> capacidad de un dato de cambiar

2) var -> sería como una variable 'global' puedo acceder desde otras partes del código (puedo tener errores si llamo a una variable de la misma manera en distintas partes del código)
let -> mejor opción para declarar una variable, estará disponible en mi bloque de código
const -> es una constante, no cambia su valor, salvo que sea un array u object, en cuyo caso puedo setear y/o agregar campos

3) para let dará error por no definirla, en var si la puedo usar, no dará error, dará undefined

4) es porque en js no necesito declarar el tipo de una variable

5) undefined la variable existe, pero no se le asignó valor (generalmente el undefined lo pone js)
lo devuelve una variable que no se le asignó nada, una función sin return o una propiedad que no exista
null es una ausancia de valor intencional, se declara la variable vacía para luego asignar valor

6) NaN es un tipo de valor numérico, se suele usar con errores de cálculo, como raices pares de número negativos, 5 + undefined

7) typeof me devuelve el tipo de dato de una variable

8) en js da lo mismo usar comilla simples o dobles. Las backticks (`) me permiten concatenar sin cerrar + y abrir, por ejemplo string = `hola ${nombre}, como va?`

function aleatorio(){
	const op1="ataque";
	const op2="defensa";
	let retorno=Math.random()<0.5 ? op1 : op2;

	return retorno;
}

function valoresTurno(){
	let ataque=Math.floor(Math.random()*100);
	let defensa=Math.floor(Math.random()*100);
	let critico=Math.random()<0.5 ? true : false;
	
	return { ataque, defensa, critico };
}

function jugarTurno(){
	let jugador=prompt("¿Ataque o Defensa?").toLowerCase();
	let maquina=aleatorio();
	let danioJugador=0;
	let danioMaquina=0;
	const valoresJugador=valoresTurno();
	const valoresMaquina=valoresTurno();

	if(jugador!="ataque" && jugador!="defensa"){
		jugador=prompt("Escriba una de las dos opciones ¿Ataque o Defensa?").toLowerCase();	
	}
	
	if(jugador === maquina) {
		if(jugador==="ataque"){			
			danioMaquina=calcularDanio(valoresJugador.ataque, valoresMaquina.defensa, valoresJugador.critico);
		}
	}
	else if ( jugador==="ataque" ) {
		danioMaquina=calcularDanio(valoresMaquina.ataque, valoresJugador.defensa, valoresMaquina.critico)/2;			
	}
	else{
		danioJugador=calcularDanio(valoresJugador.ataque, valoresMaquina.defensa, valoresJugador.critico)/2;		
	}

	return {jugador, danioJugador, danioMaquina, valoresJugador, valoresMaquina};
}
